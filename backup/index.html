Overview

A self-hosted attendance platform built for real devices.

REKABSEN connects directly to compatible attendance devices through ADMS, allowing attendance data to be collected, monitored, and exported through a lightweight self-hosted platform. Any device that supports the ADMS protocol can send data to REKABSEN.

ADMS Protocol Support

Communicates directly with any ADMS-compatible attendance device via the push protocol, with no middleware required.

Lightweight Runtime

Powered by Python's standard http.server, with minimal dependencies and maximum portability.

Secure by Default

Hashed password authentication and server-side session management out of the box.

Capabilities

Everything you need. Nothing you don't.

REKABSEN ships with a complete feature set for real-world attendance tracking, without unnecessary complexity.

ADMS Device Integration
Receives attendance data directly from compatible ADMS devices. Works with ZKTeco and any device supporting the ADMS push protocol.
Real-Time Monitoring
Live attendance feeds delivered through Server-Sent Events. No polling, no page refresh needed.
Interactive Analytics
Visualize attendance patterns with interactive SVG charts rendered natively in the browser.
Excel Report Export
Export attendance reports as XLSX files with a single click using the openpyxl library.
Lightweight Architecture
Built entirely on Python's standard library. No heavy frameworks or complex runtime requirements.
SQLite and MySQL Support
SQLite works out of the box. MySQL support available for production or multi-user deployments.
Secure Authentication
Passwords are hashed and authentication is managed with server-side sessions for secure access.
Multiple UI Themes
Choose between a modern UI or a nostalgic Windows 95-inspired theme to match your preference.
WIB Timezone Support
Native Indonesia Western Time (WIB, UTC+7) support for accurate local attendance timestamps.

Quick Start

Get Started in Minutes.

REKABSEN is designed for minimal-friction deployment. Choose your preferred installation method below.

1

Install REKABSEN

Run the one-line installer on Linux/macOS, or clone and run manually on Windows.

2

Open the dashboard

Access the admin dashboard at http://localhost:8080 once the server starts.

3

Connect your device

Point your ADMS device's server address to your REKABSEN host to begin receiving attendance data.
